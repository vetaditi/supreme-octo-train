# Wildlife Health Monitoring API Documentation

A comprehensive collection for integrating wildlife health monitoring APIs including biodiversity data, animal tracking, species observations, conservation status, and environmental data.

## APIs Covered

| API | Purpose | Auth Required |
|---|---|---|
| [GBIF](./gbif.md) | Biodiversity occurrence data | No |
| [iNaturalist](./inaturalist.md) | Wildlife observations & species ID | No (read) |
| [Movebank](./movebank.md) | Animal tracking & movement data | Basic Auth |
| [IUCN Red List](./iucn.md) | Conservation status | API Token |
| [NASA Earthdata](./nasa-earthdata.md) | Environmental & climate data | Earthdata credentials |

## Overview

This documentation covers 15 endpoints across 5 public wildlife and environmental APIs. These APIs can be combined to build comprehensive wildlife health monitoring systems that track species populations, movement patterns, conservation status, and habitat conditions.
